Why teams use FileSentinel

Attackers scrape public sites for leftover secrets. This pack hardens Cloudflare before requests hit your origin.

Safe matching

Uses ends_with and precise path checks — not naive contains ".php" that would brick your site.

Secrets & backups

Blocks .env*, .bak, .sql, dumps, keys, and common CMS config probes.

Zero deploy friction

Paste into Cloudflare Custom Rules. No plugin, no origin rewrite, no downtime.

Install in Cloudflare

Security → WAF → Custom rules → Create rule → paste expression → Action: Block.

(
  ends_with(http.request.uri.path, ".env")
  or ends_with(http.request.uri.path, ".bak")
  or http.request.uri.path contains "/.git/"
  or http.request.uri.path contains "/.env"
  /* full pack in rules/cloudflare-custom-rule.txt */
)
